# Прототип редизайну — вихідники для референсу

Копія коду інтерактивного прототипу (https://claude.ai/artifact/Hn9JBQDBjFZjwW6zGJS4up) станом на 2026-09-30.
Специфікація і план переносу — у [REDESIGN.md](../../REDESIGN.md).

| Файл | Що всередині |
|------|--------------|
| `prototype.css` | усі стилі: токени світлої/темної теми, компоненти магазину (`.card`, `.hero-card`, `.cl-stack`, `.rec-duo`…) і адмінки |
| `shop.js` | екрани Mini App (`scrHome`, `scrProduct`, `scrCart`…), варіанти вигляду (`COLL_STYLES`, `REC_STYLES`, `INFO_STYLES`, `GIFT_STYLES`), тексти змін (`NOTES`) |
| `admin.js` | сторінки адмінки (`pgOrders`, `pgProducts`…), форми-шухляди, шаблони акцій (`PRESETS`), тексти змін (`NOTES_A`) |
| `common.js` | SVG-іконки (`PATHS`, `ic()`), утиліти (`money`, `disc`), акцентні кольори (`ACCENTS`) |
| `shell.html` | оболонка прототипу (перемикач Магазин/Адмінка, мітки) — у продакшн не переноситься |

Файл `data.js` (фейковий каталог з base64-фото, ~0.5 МБ) навмисно не скопійовано, тому ці файли
не запускаються локально — це лише довідка для верстки. Живий прототип — за посиланням вище.
Мітки `nw(N)` і панель `#shop-notes` — інструменти огляду, у продакшн не потрапляють.
